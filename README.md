# NetworkingLabs


Objectives: 


-Network Implementation in GNS3  

-Build and simulate the provided network diagram in GNS3, including routers, switches, PCs, and links, with proper device labeling.

-Routing Protocol Configurations: 
 RIP, OSPF, and EIGRP across Segments 1, 2, and 3.

-Ensure correct redistribution between these protocols so all devices can communicate seamlessly.

-VLAN Setup  
  Configure VLANs 311, 321, 331, and 341, assign subnets, and ensure proper segmentation of client networks.

-EtherChannel & Spanning Tree Protocol (STP)  
  Implement EtherChannel between POS-SW101 and related switches, configure STP, and manually set one switch as the root bridge.

-IP Addressing Scheme
  Apply Class C addressing for Segments 1 & 2, and VLSM subnetting for Segment 3.

-Plan for 60 client subnets across VLANs using private IP ranges.
