Network Lab: IPv4/IPv6 Addressing & VLAN Implementation

Project Overview
This project focuses on designing a network with IPv4 and IPv6 addresses, VLANs, and trunking. The goal is to configure all devices in GNS3 to ensure full connectivity and proper network segmentation.

Objectives
- Generate IPv4 and IPv6 subnetting schemes
- Build device and network tables for PCs and servers
- Configure IPv4 and IPv6 addresses on all devices
- Label the GNS3 topology with correct addresses
- Configure VLANs and trunks (including a BlackHole VLAN)
- Verify connectivity using ping tests (both IPv4 and IPv6)
- Document all commands and screenshots

Tools & Technologies
- Cisco routers and switches (GNS3 simulation)
- IPv4/IPv6 addressing and subnetting
- VLANs and trunking
- Connectivity verification (ping)

Key Skills Demonstrated
- Dual-stack IP configuration (IPv4 & IPv6)
- VLAN and trunk configuration
- Network documentation and labeling
- Network troubleshooting and verification
